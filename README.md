# Calculadora em Python

## Sobre o projeto

Este projeto consiste em uma calculadora desenvolvida em Python, criada para praticar conceitos básicos de programação, como variáveis, operadores, estruturas condicionais e repetição, e aprimorar habilidades com git e github.

## Funcionalidades iniciais 
A calculadora permite realizar diferentes operações matemáticas, como:
* Adição
* Subtração
* Multiplicação
* Divisão
* Porcentagem
* Outras operações


## Tecnologias
* Python 
* Git e GitHub

## Objetivo
O objetivo do projeto é praticar os fundamentos da programação em Python e desenvolver a lógica de programação e apromorar habilidades com o git e github.
